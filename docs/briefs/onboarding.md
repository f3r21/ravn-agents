# Brief: codebase onboarding (`packages/onboarding`)

Research doc: `docs/research/codebase-onboarding.md`. Decisions: 9, 12, 18 (revised 2026-09-26).

## What to build
- Skill `onboard`: builds `docs/codebase-map/` in the TARGET repo — a layer generated by code
  (tree, packages, entry points, scripts) plus prose area pages written by `area-mapper` subagents
  in parallel. `INDEX.md` under 200 lines, one page per area, every claim with file:line. A
  validator rejects any cited path or line that does not exist. Stamp build SHA + per-area git
  tree hash in the map's frontmatter.
- Skill `ask-codebase`: uses the map as a router, then confirms the answer by reading the cited
  code before replying. Answers cite file:line.
- `SessionStart` hook (`hooks/hooks.json` + bundled `dist/check-map-staleness.js`): reports stale
  areas via `additionalContext`; never blocks. The empty `hooks/hooks.json` in the skeleton is yours.
- Skill or flag to refresh only stale areas.
- The map is never auto-loaded: no `@path` import into CLAUDE.md.

## Eval
20+ questions about `ravn-task-management-challenge` with reference answers and file:line evidence
(SWE-QA-style categories), including questions whose answer changed after the map's SHA and
questions the map cannot answer. Paired: plain Claude Code vs with map. `answer_accuracy_with_map`
plus tokens, wall time and tool calls; code-graded where possible, judge checked against a maintainer's
hand grading of 10 items.

## Demo target
Build the map for `ravn-task-management-challenge`, then answer a question a new engineer would ask.
